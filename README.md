# My Shop

## Опис проєкту
Система обліку товарів у невеликому магазині. проєкт на PHP: облік товарів, надходження/списання,
пошук/фільтрація/сортування, звітність та прогнозування
поповнення запасів.

## Ролі
Архітектор - проєктування структури системи
Кодер - реалізація функціоналу
Тестувальник - написання автоматизованих тестів
Адміністратор документації - ведення документації
