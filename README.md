# My Shop

## Опис проєкту
Система обліку товарів у невеликому магазині. проєкт на PHP: облік товарів, надходження/списання,
пошук/фільтрація/сортування, звітність та прогнозування
поповнення запасів.

## Ролі
Архітектор - проєктування структури системи <br>
Кодер - реалізація функціоналу <br>
Тестувальник - написання автоматизованих тестів <br> 
Адміністратор документації - ведення документації <br>

## Вимоги

Повна специфікація вимог знаходиться в папці
[`/requirements`](./requirements)


**Функціональні вимоги:**
1. Облік товарів (додавання/редагування/видалення карток).
2. Реєстрація надходжень і списань/продажів зі складу.
3. Пошук, фільтрація та сортування товарів.
4. Автоматичні рекомендації щодо поповнення запасів на основі швидкості продажів.

**Нефункціональні вимоги:**
1. Безпека: захист від SQL-ін'єкцій через підготовлені запити.
2 Продуктивність: пошук/фільтрація має відбуватись швидко.
3. Супроводжуваність: поділ на шари представлення / бізнес-логіка / доступ до даних.
